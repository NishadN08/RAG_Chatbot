# RAG Chatbot🤖👨‍💻


Welcome to my RAG Chatbot project! 
- This interactive chatbot uses Retrieval-Augmented Generation to provide accurate, context-aware answers by combining document retrieval with LLM reasoning.
- I built this system using LangChain 1.x and Ollama and have used gemma3:12b model, with full real-time streaming support for a smooth, token-by-token response experience. 
- The chatbot ingests JSONL file which contains crawled data from the website of The Department of Scientific Computing at Florida State University (sc.fsu.edu).
- It creates embeddings, retrieves the most relevant chunks, and generates high-quality answers directly grounded in the data. 
- The backend is powered by FastAPI, supports vector search, customizable prompts, and integrates easily with any frontend.
- This project is designed to be easy to run, explore, and extend—perfect for personal knowledge bases, demos, or production-level AI assistants.
